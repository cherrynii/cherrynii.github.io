UCLA Life Science Computing

Web Accessibility

I'm currently working with UCLA's Life Science Computing to improve accessibility of departmental websites so that they meet WCAG 2.1 AA accessibility guidelines. So far, I have resolved 50+ support tickets covering issues related to accessibility, mobile responsiveness, and content updates on 10+ WordPress sites.

When I'm not resolving support tickets, I use lsc-axe-core to diagnose and fix accessibility issues. My workflow involves making pull requests with Git across the ucla-child-ls, ucla-plugin-plugin-ext, and ucla-tec-templates codebases. Some fixes include updating text opacity in ucla-child-ls theme files to resolve color contrast violations and refactoring HTML header elements in PHP code to ensure a semantic structure. I also develop custom JavaScript snippets on WordPress sites to remediate issues with semantic HTML structure (heading levels, landmark roles), ARIA labels, navigation roles, and DOM clean-up.

So far, on CEILS, I've improved accessibility scores from 70% to 95%+ as measured by the lsc-axe-core scanner. Currently, I'm leading accessibility remediations for the Mildred E. Mathias Botanical Garden site.
