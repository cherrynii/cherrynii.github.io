Project 01

Chromatin State Prediction

A 1D convolutional neural network for classifying DNA sequences into chromatin states

Overview

Why a CNN?

DNA regulation depends heavily on sequence motifs — short, recurring patterns that influence how a region of the genome behaves. CNNs are a natural fit for this: they detect motifs automatically regardless of where they fall in a sequence, and reuse the same learned filters across the entire input.

For this hackathon project, I trained a 1D CNN to classify 200bp DNA sequences into their corresponding chromatin states.

Built With

  • Python
  • TensorFlow / Keras
  • One-hot Encoding
  • Convolutional Neural Networks
Data

Data Representation

Each DNA sequence was one-hot encoded, mapping every nucleotide to a 4-channel vector so the model could process the sequence numerically.

One-hot encoding scheme
Base Encoding
A[1, 0, 0, 0]
C[0, 1, 0, 0]
G[0, 0, 1, 0]
T[0, 0, 0, 1]

The dataset was split 80/20 — 80% for training, 20% for validation.

Architecture

Model Architecture

The network used 4 convolutional layers with kernel sizes of 30, 15, 7, and 3. Large early kernels capture broader motifs, while smaller kernels pick up more specific patterns as the network goes deeper. Filter counts increased from 64 to 512 across the layers.

Key Techniques

  • Dilated convolutions for long-range dependencies
  • Global average pooling to reduce overfitting
  • Label smoothing for noisy labels
  • AdamW optimizer + dropout
Augmentation

Reverse Complement Augmentation

DNA is double-stranded, and motifs can appear on either strand. To account for this, I trained the model on each sequence alongside its reverse complement — effectively doubling the dataset size and improving generalization.

Results

Results & Takeaways

The model reached a top validation accuracy of 19.5% on this multi-class chromatin state classification task — a solid baseline for a hackathon timeframe, and a clear signal for where the next iteration should focus: more training data, deeper motif architectures, and further tuning of the augmentation strategy.
